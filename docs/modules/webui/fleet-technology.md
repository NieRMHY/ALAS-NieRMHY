# 舰队科技

入口为「舰队管理 → 舰船数据 → 舰队科技」，路由 `/i/:instance/task/FleetAnalysis?tab=technology`。

累计获取、满星、120级里程碑是唯一正式统计依据，均为已完成／未完成两态。表格只展示有科技奖励的舰船，一种一行；当前持有数量和最高等级放在舰名提示中，退役不回退科技。每项数字格分别按里程碑高亮，120级完成同时高亮编号、名称、阵营和舰种，三项完成才高亮合计。

筛选支持类别、稀有度、阵营、加成舰种、加成属性和完成情况，额外筛选区分解锁与120级加成。所有数据列可排序，表格内部独立滚动。每千心智科技点使用完整100→120级费用；满级待觉醒由玩家设置，选中为橙色，并与养成页共享。具体选项见 [舰船数据](fleet-analysis.md)。

打开记录编辑模式后点击里程碑或属性格切换，统一保存并实时预览统计。获得与解锁共用状态，120级与120级加成共用状态；点亮满星或120级自动补记获得，常规舰船点亮120级还补记满星。取消获得清除满星和120级，常规舰船取消满星清除120级。手动修改不因当前舰船状态矛盾而拒绝；保存仍检查数据版本。

里程碑独立保存，仅首次建立舰船数据时初始化一次，后续舰船变动不自动补记。点击「合并舰船数据」才将当前舰船的正向事实并入已有里程碑，只增加、不删除；已有草稿须先保存或放弃。

阵营科技等级单独维护，空值为未知，0 表示确认未升级。属性加成分别显示舰船科技、阵营科技及总加成；阵营表使用所选等级的累计值，避免重复相加。

静态奖励资料来自离线打包的 `assets/ship/fleet_tech.json`，名称与身份关联 `ship_data.json`，来源版本可在页面查看。舰船数据写入时，已知等级低于70级强制未满星，身份确认的常规舰船100级及以上强制满星；其余保留原三态值。我的舰船对旧记录只读显示相同默认状态。科研、META和原生UR不适用常规舰船的高等级规则。科技读取使用独立里程碑，不重新推算。筛选、排序及显示开关按实例记住，页面不定时刷新。

详细的数据流、存储、迁移和接口见 [舰船数据](fleet-analysis.md)，实施目标见 [重构计划](fleet-data-refactor-plan.md)。旧的数据/人工合并视图与低高等级切换已移除。
