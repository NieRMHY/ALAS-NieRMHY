# 船坞航空图标

`dock_aircraft_icon.png` 是 22×14 的灰度二值字形，来自原生 1280×720 船坞截图。
公开回归夹具 `tests/fixtures/mind_lua_names.png` 的第一张卡片（纳希莫夫海军上将）
包含同一原图裁剪；字形为夹具的 `(15, 7, 37, 21)`，取 RGB 最小值大于 205 的白色像素。

计算器只在精确识别与有界复读失败后使用该图标区分近似名单候选。
在卡片 `(x, y, x+40, y+30)` 内对白色字形做归一化模板比较，达到 0.85 才提供航母证据。
国服 Lua 的 `ShipType.Type2Print` 将轻航、正航均映射为 `hangmu`；航战、潜母也有飞机字形。
该图标不表示基础稀有度，不能细分这些舰种；目录改造别名沿用基础舰种时，也不能排除战列改造为航战的身份。

独立反例为同一夹具中的普通战列、META 战列、轻巡；另一张正航“小大凤”用于正例，不能用它生成模板再验证自己。
该灰度字形与现有船坞等级、编队字形同属直接加载资源，不参与按钮生成器。
